# Thunderbolt — ForteBank video analysis

Исходный код экспериментального сервиса анализа кассовых видео. Структура `outputs/` сохранена относительно локального проекта.

## Компоненты
- `outputs/forte_r3d_web`: основной UI, Python backend и API для жюри.
- `outputs/forte_qwen30`: frozen Qwen3-VL observations, обучение классификаторов и inference.
- `outputs/forte_transfer30`: событийный классификатор и локализация.
- `outputs/forte_improved`, `forte_model`, `forte_temporal_mil`: визуальные признаки и эксперименты.

## Важные ограничения
Это публичный **снимок исходников**, не автономный установщик. Веса, обученные классификаторы, приватный датасет, служебные метаданные и зависимости сторонних репозиториев не включены. Простое клонирование не запустит готовую модель.

Текущий ансамбль: Qwen3-VL-4B + DINOv2 + R3D18 + ResNet18, frozen encoders, readout обучен на 30 видео. На 10 отложенных от текущего fit видео: accuracy 50%, positive F1 61.54%, ROC AUC 0.56. Эти видео использовались в исторических экспериментах; независимая внешняя оценка отсутствует. Классы событий и таймкоды требуют проверки человеком.

## Запуск после восстановления локальных ресурсов
1. Python, виртуальное окружение и `pip install -r requirements.txt`. Совместимость версий на новом компьютере отдельно не проверена; сериализованные sklearn-модели требуют совместимых версий.
2. Восстановите ресурсы согласно `MODEL_ASSETS.md` из своей разрешённой локальной копии.
3. `python outputs/forte_r3d_web/server.py` — UI на 127.0.0.1:8765.
4. `python outputs/forte_r3d_web/jury_api.py` — API на 127.0.0.1:8766. Ключ создаётся локально; не коммитьте его.

## API
`POST /api/v1/analyze`, multipart поле `file`, .mov; авторизация `X-API-Key`.
`GET /api/v1/jobs/{job_id}` — processing/done/failed, verdict и violations с кадрами JPEG base64.
Результат API — модельный прогноз. Разметка исходного датасета не является прогнозом модели.

## Нормативные основания
Каталог `fortebank_cash_rules.json` и условные сопоставления `event_rule_mapping.json`.
Ссылка на норму не подтверждает нарушение. Применимость, исключения и редакция источника требуют проверки.

## Данные и публикация
В репозитории нет банковских видео/кадров, ключей, весов и результатов с изображениями. Не добавляйте их без проверки прав. Публикация кода не создаёт работающий сайт: для доступа без ноутбука нужен сервер. Лицензии сторонних моделей и кода проверяются отдельно; данный репозиторий не меняет условия их использования.
